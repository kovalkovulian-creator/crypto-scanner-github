# Крипто-сканер — проверка мемкоинов на скам

Цель проекта: полуавтоматическая система, которая отсеивает скам среди новых монет на Solana
и присылает сигналы. Решение о сделке принимает человек. На реальные деньги торгуем
только после того, как бумажный журнал покажет плюс.

## План
- [x] **Шаг 1.** `scam_check.py`: проверка одной монеты по адресу (RugCheck + DexScreener)
- [x] **Шаг 2.** `scanner.py`: сканер новых монет + сигналы в Telegram + журнал `journal.csv`
- [ ] **Шаг 3.** Бумажный журнал сигналов, через 3–4 недели разбор статистики
- [ ] **Шаг 4.** Реальные сделки на минимальную сумму, только если шаг 3 в плюсе

## Как запустить (Mac)
В Терминале:
```
cd ~/Claude/crypto-scanner
python3 scam_check.py <адрес_монеты>
python3 scam_check.py <адрес_монеты> --json
```
Адрес монеты (mint) берётся на dexscreener.com или pump.fun.
Пример (BONK): `python3 scam_check.py DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263`

Дополнительные библиотеки не нужны, хватает стандартного Python 3.

## Что проверяет
- **Критично (красный):** не отозвано право выпуска или заморозки; у топ-10 кошельков ≥50%;
  у создателя ≥10%; ликвидность < $10k; RugCheck пометил монету как rugged.
- **Настораживает (жёлтый):** у топ-10 30–50%; ликвидность заблокирована меньше чем на 50%;
  паре меньше суток; продаж вдвое больше покупок; нет соцсетей; инсайдеры.

Пороги задаются в начале файла, их можно подкручивать.

**Важно:** скрипт оценивает риск скама, а не прогнозирует цену. «Зелёный» не значит «вырастет».

## Сканер (шаг 2)
```
python3 scanner.py --test    # проверить связь с ботом (один раз)
python3 scanner.py --once    # один проход
python3 scanner.py           # работать постоянно (стоп: Ctrl + C)
```
Источник монет: свежие профили и бусты DexScreener (Solana). Сигнал приходит, только если монета
не красная, ликвидность ≥ $30k, топ-10 ≤ 40%, предупреждений ≤ 2. Фильтры в начале `scanner.py`.
Каждый сигнал пишется в `journal.csv` — это бумажный журнал для шага 3.

**Автоотчёты в бот:** через 1 ч, 24 ч и 7 дней после сигнала сканер отвечает на исходное сообщение:
изменение цены, ликвидность, итог (плюс / минус / скам). В 21:00 — дневная сводка.
Состояние отслеживания хранится в `signals.json`. Отчёты идут, только пока сканер запущен
(если был выключен — после запуска пришлёт последний пропущенный отчёт).

## Проверка сигналов
```
python3 review.py
```
Сравнивает цену в момент сигнала (из journal.csv) с текущей. «СКАМ» — ликвидность < $1k или падение ≥ 90%
(фильтр ошибся). Итоги сохраняются в review.csv. Смотреть через сутки и через неделю после сигнала.

## Автономная работа (GitHub Actions)
Сканер запускается на серверах GitHub каждые ~10 минут (`.github/workflows/scanner.yml`, режим `scanner.py --cycle`).
Токен и chat_id — в Settings → Secrets → Actions репозитория (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`), не в файлах.
Журнал (`journal.csv`, `seen.json`, `signals.json`) сохраняется коммитами в репозиторий — актуальная версия там, а не на Mac.
Загружать на GitHub папку `crypto-scanner-github` (в ней нет config.json с токеном).
